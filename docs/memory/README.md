# HCA System — Permanent Memory

This folder is the project's permanent memory (owner rule 12). Read it before making changes.

| Document | Use it for |
| --- | --- |
| [PROJECT_MEMORY.md](PROJECT_MEMORY.md) | The 15 mandatory standing conventions, owner aliases (OTMS/Costing), delivery checklist |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Stack, folder layout, request flow, auth/RBAC, audit, database, deployment |
| [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) | Navy/white visual language, tokens, typography, components, accessibility |
| [MODULES.md](MODULES.md) | Honest module map and delivery status |
| [DECISIONS.md](DECISIONS.md) | Architecture decision records (ADRs) |
| [../CHANGELOG.md](../CHANGELOG.md) | Running log of every change |
| [../changes/](../changes/) | One detailed note per delivery |

## How to use the memory

1. **Before work:** read `PROJECT_MEMORY.md` and the sections of `ARCHITECTURE.md` /
   `DESIGN_SYSTEM.md` relevant to the task.
2. **During work:** apply the 15 rules by default; they are not optional for "later".
3. **After work:** add a `CHANGELOG.md` entry and a note in `docs/changes/`; update the memory
   documents if a pattern, module status or decision changed.
